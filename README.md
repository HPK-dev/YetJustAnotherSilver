# Yet Just Another Silver

## Motivation

Some Fabric modpacks need silver resources exposed through conventional `c` tags.
This mod provides silver without requiring another content mod.



## Features

Add (deepslate) silver ore, raw silver ,silver ingot, silver nugget and block of silver.
