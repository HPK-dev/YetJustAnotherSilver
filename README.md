# Yet Just Another Silver

## Motivation

Our server needed a small, standalone source of convention-tagged silver, so we created a mod that adds just silver without requiring a larger technology mod.



## Features

Add (deepslate) silver ore, raw silver ,silver ingot, silver nugget and block of silver.

This branch supports Fabric on Minecraft 1.20.5 and 1.20.6 with Java 21.
